# EditionController

`CodeAcademyWeb/Controllers/EditionController.cs`, route `api/Edition`. Contract: Swagger (`/openapi/v1.json`).

| Dependency | Implementation |
|------------|----------------|
| `IEditionsService` | `AcademyPersistance/Services/EFEditionsService.cs` |
| `IMapper` | `CodeAcademyWeb/Profiles/EditionProfile.cs` |

## Mapping

- `Edition` ↔ `EditionDTO`: by property name (`Id`, `Code`, `Description`, `RealPrice`).
- `Edition` → `EditionDetailsDTO`:
  - `StartDate`, `FinalizationDate`: `LocalDate` as `yyyy-MM-dd`.
  - `InstructorFullName`: `"{Instructor.Firstname} {Instructor.Lastname}"`.
  - Flattening: `CourseTitle` from `Course.Title`, `InstructorFirstname` / `InstructorLastname` from `Instructor`.
- `EditionDetailsDTO` → `Edition`: `StartDate` and `FinalizationDate` parsed from `yyyy-MM-dd` (`LocalDateExtensions.Parse`); the read-only fields are ignored.

## Endpoints

### `GET /api/Edition` — `GetAll`

- **Flow**: `GetAllEditions()` → `IEnumerable<EditionDTO>` → 200.

### `GET /api/Edition/{id}` — `FindById`

- **Flow**: `GetEditionById(id)` → `EditionDetailsDTO` → 200.
- **Handled errors**: `null` → `NotFound()`: 404 with the `ProblemDetails` generated by `[ApiController]`, not an `ErrorObject`.
- **Known issues**: non-uniform 404 body (`docs/suggestions/2026-11-05-404-edition-get-non-uniforme.md`). The tests follow Swagger (404 `ProblemDetails`).

### `POST /api/Edition` — `Create`

- **Flow**: `EditionDetailsDTO` → `Edition` → `CreateCourseEdition(edition)`; the id assigned by the service on the same instance is mapped back → 201, `Location` `/api/edition/{id}`.
- **Handled errors**: `EntityNotFoundException` (course or instructor missing) → 400 `ErrorObject`.

### `PUT /api/Edition` — `Edit`

- **Flow**: `EditionDetailsDTO` → `Edition` → `EditCourseEdition(edition)` → 200 with `EditionDetailsDTO`.
- **Handled errors**: `EntityNotFoundException` with `EntityName` `Edition` → 404; any other `EntityName` (course, instructor) → 400 `ErrorObject`.
- **Known issues**:
  - The 404 body is a plain string instead of an `ErrorObject` (`docs/suggestions/2026-11-05-errore-404-put-edition-non-uniforme.md`).
  - `EFEditionsService.EditCourseEdition` does not check that the edition exists, so the 404 branch is never reached with the real service (`docs/suggestions/2026-11-06-edit-edition-missing-existence-check.md`). The tests simulate the exception with the mock.

### `DELETE /api/Edition/{id}` — `Delete`

- **Flow**: `DeleteCourseEdition(id)` → 204.
- **Handled errors**: `EntityNotFoundException` → 404 `ErrorObject`.

### `GET /api/Edition/course/{id}` — `GetEditionsByCourseId`

- **Flow**: route `id` (course id) → `GetEditionsByCourseId(id)` → `IEnumerable<EditionDetailsDTO>` → 200.

### `GET /api/Edition/studentAvailable/{id}` — `GetAvailableEnrollmentByStudentId`

- **Flow**: route `id` (student id) → `GetAvailableEnrollmentByStudentId(id)` → `IEnumerable<EditionDetailsDTO>` → 200.
